# Changes waiting for the next app update

The desktop app gets an update once 10 changes have piled up here, unless Ryan asks for one sooner.
Add one line per change. `tools/publish_update.py` publishes them and empties this list.

- A Practice button on the Play page: the computer, the daily puzzle, the tutorial and testing a deck now have their own page.
- DON!! can't be added, returned, rested or readied by hand in any match against someone (Friends only and the computer too), unless a card's ability calls for it.
- Abilities that add DON!! from the DON!! deck add them rested or active as the card says, with no choice.
- Every card's name, cost, power and types match the official English card list (525 cards' types and 70 names corrected), so abilities that name a type or card find them.
- Weekly challenges: three goals a week in Profile (the same for everyone), each finished one a badge.
- Spectator chat: people watching a live match can cheer with emotes and short phrases, shown to everyone at the table (players can hide it).
- Sealed packs (Practice): open 6 packs of a set, build a 30 to 50 card deck from what you pull, and play the computer's own sealed deck or save it for Casual.
